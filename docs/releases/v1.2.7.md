# v1.2.7 更新说明

本版本简化 BoyFriend 直播间的添加流程，并修复构建、部署与 Go 1.26 兼容性问题。

## BoyFriend 房间号自动补全

- 添加“自动补全 BoyFriend 直播间链接”开关，默认开启。
- 开启后只需输入房间号（例如 `tommyjoyer`），即可自动转换为 `https://zh.boyfriend.show/tommyjoyer`。
- 输入完整的 BoyFriend 链接或其他平台直播间链接时保持原样，不会与自动补全冲突。

## 构建与部署

- Docker Compose 默认仅监听本机 `127.0.0.1:8080`，降低未配置访问控制时意外暴露服务的风险。
- 修复 Dockerfile 下载 Release 资产时使用了错误仓库地址的问题。
- 将开发环境和文档中的 Go 版本要求统一为 Go 1.26。
- 适配 Go 1.26 的反向代理 API，并清理已不再使用的录制与 HLS 代码。
- 更新 GitHub Actions 中已停止维护的旧版发布、覆盖率与脚本动作。
