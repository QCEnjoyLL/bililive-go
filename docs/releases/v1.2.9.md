# v1.2.9 更新说明

本版本修复在线鉴权、录制停止与计时、分层配置和后处理任务并发问题。

## 在线鉴权与房间删除

- 在线开启或关闭 Web 鉴权、修改用户名或密码后，新请求立即使用最新配置，无需重启服务。
- 删除直播间时同步停止录制，修复未开启监听的手动录制在删除房间后仍继续运行的问题。

## 录制计时与配置继承

- 整场录制时长从本次录制开始时计算，分段和断流重试不再重置截止时间。
- 整场截止检查独立于分段收尾执行；停止录制时停止房间监听，避免自动重录。
- 停止后取消本次录制的定时器，避免旧定时器影响后来重新开启的录制。
- 修复全局流偏好未被房间继承的问题，平台和房间仍可按层级覆盖。
- 定时分段、定时停止和标题变化分段使用房间实际生效的配置，正确应用平台与房间覆盖设置。

## 后处理任务

- 多个调度入口同时触发时，运行中的任务仍遵守配置的并发上限。
- 任务启动状态保存失败时释放并发名额；管理器关闭后不再启动新任务。

上述修复均补充了回归测试。
